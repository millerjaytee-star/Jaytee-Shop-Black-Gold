Controlled pilot security

Security & Trust

Stabilis handles operating and financial information as tenant-scoped business data. These statements reflect controls implemented in the dedicated Stabilis environment.

Tenant isolation

Organization + location boundaries

Supabase Auth, organization membership, assigned-location checks and Row Level Security control customer access. Anonymous tenant-data access is denied.

Private storage

Source, report and evidence buckets

Customer source files, reports and evidence use private storage boundaries. No service-role credential is shipped to the browser.

Financial truth

Deterministic before generative

Financial calculations, opportunity totals, rollups and Verified Value are not delegated to an LLM. AI may explain authorized structured results.

Release control

Shadow mode

Initial pilots support engine finding → analyst review → operator context → approved release. Modeled opportunity is not verified savings.

Verification

Evidence before value

Verified Value requires a baseline, measurement window, evidence, adjustments and a review decision.

Telemetry

Privacy-conscious product analytics

Product usage events are designed not to copy raw financial file contents into general usage telemetry.
