# Verified Value Methodology

Stabilis maintains four distinct financial states:

1. **Estimated / Modeled Opportunity** — potential recoverable value under stated methodology and confidence.
2. **Action Underway** — an approved opportunity is being addressed.
3. **Observed Improvement** — a measurable post-intervention change exists.
4. **Verified Value** — financial impact passes evidence, adjustment, attribution and reviewer requirements.

Modeled opportunity is never relabeled as savings. Harbor & Hearth remains a fictional controlled example with `$392,570.56` modeled recoverable opportunity and `$0` Verified Value.
