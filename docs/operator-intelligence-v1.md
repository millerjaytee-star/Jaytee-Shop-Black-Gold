# Operator Intelligence v1

## Customer journey
Public Stabilis site → Profit Leak Score → diagnostic conversation → account/onboarding → organization/locations → fiscal setup → upload → mapping/validation → diagnostic run → analyst review → approved report → action plan → result tracking → recurring intelligence.

## Command Center
The default view answers: what is happening, how large the modeled opportunity is, where it occurs, what matters most, what to do next, what has been fixed, and how reliable the data is.

Core workspaces: Command, Locations, Opportunities, Labor, Food & Inventory, Revenue, Market Intelligence (only when sourced), Action Center, Results/Verified Value, Reports, Data & Connections and Settings.

## Analyst workbench
Analysts review data quality, mappings, periods, anomalies, calculations, evidence, opportunity deduplication, confidence, recommendations, reports and verified-value claims. AI cannot self-approve or self-verify.

## Demo
Harbor & Hearth is a fictional 10-location restaurant group. It demonstrates HHR-07/HHR-08 labor risk, HHR-09 food/inventory risk, HHR-10 revenue decline, actions, data quality and the strict distinction between modeled opportunity and verified value.
