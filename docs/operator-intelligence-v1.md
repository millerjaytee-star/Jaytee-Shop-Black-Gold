# Operator Intelligence v1

## Customer journey
Public Stabilis site → Profit Leak Score → diagnostic conversation → account/onboarding → organization/locations → fiscal setup → upload → mapping/validation → diagnostic run → analyst review → approved report → action plan → result tracking → recurring intelligence.

## Command Center
The default view answers: what is happening, how large the modeled opportunity is, where it occurs, what matters most, what to do next, what has been fixed, and how reliable the data is.

Core workspaces: Command, Locations, Opportunities, Labor, Food & Inventory, Revenue, Market Intelligence (only when sourced), Action Center, Results/Verified Value, Reports, Data & Connections and Settings.

## Analyst workbench
Analysts review data quality, mappings, periods, anomalies, calculations, evidence, opportunity deduplication, confidence, recommendations, reports and verified-value claims. AI cannot self-approve or self-verify.

## Diagnostic readout and 90-day roadmap

Select the agreed location in the customer workspace and open **Reports → Diagnostic readout and roadmap**. The analyst can reach the same readout from **Diagnostic Review**. It assembles up to eight recent released weekly findings with source links, variance components, coverage gaps and separate fields for modeled opportunity, observed change and client-verified impact. It also includes shared diagnostic inventory and waste evidence for that location. The weekly review supplies no opportunity estimate when an approved supported estimate is absent.

Enter the agreed roadmap start date to place up to five owner-approved weekly actions into the three 30-day phases. Each action retains its owner, measure, evidence requirement, due date, next review and source review link. The date is used for the current view and printable export. The generated readout reflects current released records. A signed version and any factual correction pass are delivered under the client’s agreed scope and kept in its restricted folder.
