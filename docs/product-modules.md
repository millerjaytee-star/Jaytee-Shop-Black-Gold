# Operator Intelligence Workspace Map

Customer product navigation:

**OPERATE** — Command Center, Locations, Labor, Forecast, Inventory, Purchasing, Food Cost, Revenue.

**EXECUTE** — Opportunities, Actions, Results / Verified Value, Reports.

**INTELLIGENCE** — Intelligence, Alerts, Data Quality / Connections, Operator Notes.

**ADMINISTRATION** — Onboarding, organization/settings for authorized administrators.

Internal reviewer roles additionally receive Analyst Workbench, Diagnostic Review, Mapping Review, Verification Review and Customer Administration.

The public demo implements the same information architecture with fictional data so the marketing experience, product proof and secure customer application remain one product family.
