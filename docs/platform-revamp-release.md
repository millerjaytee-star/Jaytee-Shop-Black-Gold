# Stabilis Operator Intelligence — Unified Platform Revamp

This release makes Stabilis one product system rather than a consulting site plus a separate demo.

- Public website introduces Operator Intelligence and shows a clearly labeled fictional command-center preview.
- `/operator-intelligence` is the interactive Harbor & Hearth fictional demo.
- `/operator-intelligence-report` is the traceable fictional sample report.
- `/login` handles production Supabase authentication and recovery.
- `/app` is the secure customer command center backed by tenant-scoped Supabase data.
- Supabase stores pilot/onboarding/feedback/notes/telemetry state and exposes a compact authenticated workspace RPC.
- Analyst-only workspaces remain role gated.
- Customer workspaces show `Not enough data` instead of demo values when authorized customer data is unavailable.
- Canonical financial rollups count PRIMARY opportunities only; HHR-07 overtime remains supporting evidence.
- Modeled Opportunity and Verified Value remain separate states.

Controlled pilots begin in shadow mode:
`DATA → VALIDATE → CALCULATE → FINDING → ANALYST REVIEW → OPERATOR CONTEXT → APPROVED RELEASE → ACTION → OBSERVE → VERIFY`

Real-world engine calibration, customer-value validation and product-market fit require actual pilot evidence and are not implied by synthetic fixture or infrastructure validation.
