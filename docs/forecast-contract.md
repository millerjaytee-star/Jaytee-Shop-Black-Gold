# Forecast Intelligence Contract

Forecast objects retain model/version, generated date, input window/manifest, horizon, output, confidence and eventual actual/error/accuracy. Forecast values remain separate from scenario values and canonical opportunity.

Internal inputs can include historical sales, transactions, average check, labor, location patterns, operating hours, holidays and promotions. Weather, events, regional economics, tourism, sports and commodity factors are displayed only after a reliable source is connected and attributable.

When history or source quality is insufficient, the product displays `Not enough data` rather than fake confidence.
