# Controlled Pilot Operating Model

Initial real-customer work runs in **SHADOW MODE**.

1. Customer onboarding and authorized data collection.
2. Ingestion, mapping, validation, normalization and reconciliation.
3. Deterministic metrics, scores, forecast outputs and canonical opportunities.
4. Analyst review of data conflicts, confidence, financial materiality and recommendations.
5. Operator validates operational context.
6. Approved intelligence is released.
7. Opportunities create owned actions.
8. Stabilis records observed outcomes.
9. Verification review determines whether any financial impact qualifies as Verified Value.
10. Calibration events capture engine prediction, analyst agreement, operator agreement, implementation and eventual result.

Pilot success is evaluated separately from customer financial performance using onboarding completion, time-to-first-diagnostic, opportunity acceptance, action creation/completion, analyst review time, login/return frequency, report usage and verified-value conversion.
